# 品牌商品发布检查

入口：品牌经营概况 → 检查商品发布资料，或 `/ops/sites/{siteId}/catalog`。商品主图、富文本、SKU、市场价格和库存仍由原生 Saleor Dashboard 编辑，本模块读取当前数据并指出问题，不另外维护商品副本。

## 凭证与范围

服务器配置 `OPS_CATALOG_SALEOR_TOKEN`，需要原生 `MANAGE_PRODUCTS` 权限；未单独配置时使用现有 `SALEOR_APP_TOKEN`。不要将凭证放进公开环境变量或浏览器。原生权限允许商品管理，因此要保护凭证；本模块只有读取、CSV格式校验和原生资料核对，不调用商品写入接口。

品牌分析员仅能读取授权品牌的检查及模板；管理员可运行CSV格式校验、原生核对并打开原生编辑入口。每个产品页只查询可信品牌的一项市场，返回结果再核对市场归属；其他品牌的市场、价格和库存不序列化到页面/API。共享Core中的商品名称、描述和属性可能供多个品牌复用，这个检查不会改变共享商品的所有权。

## 检查项目

| 类别 | 检查 | 处理 |
| --- | --- | --- |
| 必要资料 | 商品图片、SKU、规格、当前市场价格 | 在原生商品编辑页补齐 |
| 市场可售 | 市场启停、发布/购买开关和生效时间、列表展示 | 在 Channel 分配与发布配置修正 |
| 库存策略 | 当前市场默认配送上下文的可售量、是否跟踪库存 | 核对仓库/国家配置；不跟踪库存需明确经营策略 |
| 实物资料 | 规格/商品/商品类型的有效重量 | 使用原生继承规则核对；数字商品不要求重量 |
| 内容质量 | 真实品牌属性、分类、描述、SEO标题/描述、图片替代文字 | 补真实商品事实，不拿分类或店铺名称冒充厂家 |

每页最多25个商品、每商品最多50个规格，提供下一页商品。超过50规格明确提示未完整检查，不能宣称全部规格通过。矩阵展示本品牌各市场的价格/发布状态；库存值只针对所选市场的默认配送上下文，不能当作所有国家库存。市场未来发布时间和停用状态不能算当前可售。

未发现问题也不等于正式开卖：配送范围、收单资格、翻译、联系/退货/隐私政策以及目标国真实地址需在品牌上线验收页另行记录。

## CSV资料准备

下载模板，替换占位SKU、USD币种、图片地址和其他示例值。模板字段：`sku,channel,price,currency,weight_kg,image_url`。适用于实物商品准备；免费/数字商品单独处理，避免批量默认策略误用。

单次文件最多1MB/2000行，支持UTF-8 BOM、标准逗号和引号换行。检查表头、列数、SKU、重复SKU/市场组合、可信品牌市场、正数价格/公斤重量、三位大写币种和HTTPS图片URL格式。错误可下载，文本做表格公式防护。

两个按钮有不同含义：

| 操作 | 核对范围 | 成功状态 |
| --- | --- | --- |
| 校验资料 | 文件和字段格式、配置中的品牌市场 | 格式校验通过，未写入商品 |
| 核对原生SKU与币种 | 格式通过后，查询原生全局SKU索引；唯一现有SKU、商品及规格均分配到该品牌市场、市场启用、币种匹配及原生价格精度 | SKU与市场币种核对通过，未写入商品（含原生价格精度） |

原生核对不受发布清单的25商品/50规格显示上限限制。全文件SKU去重后每100个查询一次，整批20秒预算、单次最多8秒；上游错误、分页未完整或结果身份异常均拒绝整批，不使用部分成功。不存在、重复及仅属于其他品牌市场的SKU统一显示“当前品牌市场找不到唯一现有SKU”，不泄露其他品牌名称/市场/价格。返回检查时间，但该快照不锁定数据，也不能作为之后写入的授权；写入时必须重新核对。

客户端直接上传文件字节；服务端独立执行1MB流式上限并严格拒绝无效UTF-8，不依赖客户端或Content-Length。格式失败不会读取Saleor，原生服务不可用返回明确错误，不展示核对成功。

价格精度来自当前规格市场价格的原生`Money.fractionDigits`；与Saleor价格写入校验一样，先忽略尾随零，再拒绝超出币种精度的非零小数。使用字符串核对，不做浮点转换、自动四舍五入或维护独立Intl/Babel币种表。未设置原生价格时不能完成这一项，明确提示先在原生后台设置；字段缺失、精度或币种资料异常拒绝整次请求。

**两种检查均不写入商品，也不是完整导入验收。** 尚不创建/修改商品，不下载图片，不验证库存/重量、图片可访问性，也不处理新SKU创建冲突。正式批量导入需后续使用原生 bulk API，并补齐预览、完整冲突检查、权限、写入结果、恢复能力及提交时数据重读。

## 原生批量运营

管理员可从当前品牌/市场打开原生批量向导；市场ID由原生查询返回，不从商品数量或市场slug推测，停用/异常市场关闭入口。分析员看不到写入入口，原生窗口仍需原生员工登录及权限。地址前缀和当前市场均保留；源码验收见对应PR。

源码已有原生 Channel 批量向导，支持已有商品分配、按商品统一规格价格/成本、仓库库存和表格粘贴；优先复用这条链路，不另建影子商品/价格数据库。本批修复规格读取或写入失败后提前发布、达到500上限后仍把未完整规格视作成功的问题；验收以对应PR为准。库存会影响共享仓库，跨批写入可能部分保存，并不是事务或新SKU CSV导入。范围、失败处理和验收见[原生商品批量运营](native-catalog-bulk-operations.md)。

## 验收记录

测试覆盖品牌/市场越权、意外上游归属、原生日期与价格/库存状态、数字商品重量策略、CSV引号/超限/重复/错误下载、原生核对完整性/批次/预算/币种/规格市场及接口重新授权/Origin。CI使用专用随机商品读取凭证和真实Saleor fixture检查报告；原生核对验收比较前后价格/市场数据，并检查其他品牌SKU拒绝与手机格式/核对状态及错误下载。临时凭证只存在该CI环境，不用于生产；最终验收结果见对应PR。
