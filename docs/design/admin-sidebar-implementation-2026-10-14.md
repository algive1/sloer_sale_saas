# 后台侧边导航原型落地

日期：2026-10-14（Asia/Tokyo）。参考 [原型图片](./admin-prototype-2026-10-13-v2.png) 与 [设计说明](./admin-prototype-2026-10-13.md)。本轮范围仅为 Dashboard 侧边导航；没有修改经营总览、Storefront、后端、SSO 或部署配置。

## 理解与实施范围

先对照原型和代码核对菜单、布局与权限，再分步修改外壳、菜单样式及选中判断。现有侧栏宽 296px，品牌图形倾斜，一级分组和二级菜单同时使用底色与边线，行高和间距也大于原型。

用户明确选择：“保留全部入口，按原型统一样式与层级”。因此保留原生页面、草稿订单、客户类型、内容模型、语言翻译、安装扩展、第三方入口、导航收藏和工具快捷入口。菜单较多时在中间区域滚动，设置与账号区保持可达。真实菜单数量、折叠状态、权限和账号文字不强行伪装成原型截图；不宣称整张侧栏与位图逐像素相同。

## 最小改动

- 展开侧栏与手机抽屉宽 264px，桌面图标栏继续为 72px，保留折叠记忆。
- 品牌区高 56px，使用平面 S 描边标识、紧凑品牌文字、灰色 Admin 标签和双箭头折叠按钮。
- 搜索框高 34px；一级菜单高 34px，二级菜单高 31px；使用无底色的缩进层级，当前页面显示浅蓝灰选中条。
- 使用现有 Lucide 图标，导航主图标显示为 18px、1.5px 描边；父级分组去除额外高亮块与左侧强调线。
- 账号区高 76px，保留真实头像、姓名/邮箱、反馈、账号菜单、主题切换、强调色偏好与退出功能。
- 所有侧栏色值集中在 `CommerceSidebar.module.css` 的作用域变量中；浅色默认强调色改为雾蓝 `#496786`，深色模式复用 Macaw 令牌并提高文字对比度。没有导入店铺主题或新增组件库。

主要代码位于 `dashboard/src/components/Sidebar/`。导航结构继续由 `menu/hooks/useMenuStructure.tsx`、权限过滤与原有 Ops 注册表生成，没有复制导航路由或删减真实功能。

## 选中态根因修复

所有嵌入 Ops 页面共用 `/commerce-ops?path=…`。原 `isMenuActive` 在比较前删除查询参数，导致打开任意 Ops 页面时所有 Ops 菜单同时被选中，父级分组也被误判为当前分组。

在既有 `commerceOpsLinks.ts` 中增加匹配逻辑，复用 `CommerceOpsPage` 的合法路径校验，按嵌入目标的路径与 `pageType` 区分菜单。经营总览与分析子页、首页装修与商品详情模板分别高亮；品牌详情仍归属“品牌站点”。缺少或非法 `path` 时，与真实嵌入页面一样回退到经营总览。

新增 17 项回归断言：14 个注册入口逐项唯一选中、两个回退情形和品牌详情归属。同一组断言修复前失败，修复后通过。证据保存在本机 `.local/admin-sidebar-20261014/selection-before.log`。
