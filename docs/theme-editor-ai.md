# Theme editor AI — Images-only release

The active operator UI supports **image generation only**. The older conversational
page/text generation route remains in source for future reuse but returns HTTP
404 unless `THEME_AI_TEXT_ENABLED=true` is deliberately set on the server.
Do not enable that flag for this release. No text, layout, product, SKU or checkout
data is generated by the image endpoint.

## Operator workflow

1. Configure `THEME_AI_ENCRYPTION_KEY` as a persistent 64-hex-character value,
   and (if using a third-party compatible gateway) add the exact HTTPS base URL
   to `THEME_AI_ALLOWED_ENDPOINTS` in your server configuration.
2. Restart/recreate the Storefront container to load these environment variables.
3. In `/ops/themes`, choose the brand/channel/locale and select **AI 图片**.
4. Under **模型设置**, create a profile with the exact image-capable model ID,
   e.g. `gpt-image-1`, an OpenAI official or compatible gateway base URL,
   and its API Key. Save and activate that provider. Model support and billing
   are determined by the provider; chat-only models will not generate images.
5. Select an existing **Hero** or **Editorial** block, choose a style, size and prompt.
   Click **生成 1 张图片**. Preview the compressed image before using it.
6. Click **确认上传并应用到当前模块**. This uploads the WebP to the existing
   authenticated Saleor media backend and updates only that module's `imageUrl`
   in the editor. Click **保存草稿**, **保存为模板** or explicitly **发布上线**
   using the existing Puck workflow.

## Trust and failure boundaries

- The image endpoint only calls `POST {baseUrl}/images/generations`, requesting
  one `b64_json` image. Compatible gateways **must** return actual base64 bytes;
  external/transient provider image URLs are deliberately rejected to avoid SSRF
  and expired published media.
- Responses are checked for MIME, image dimensions/decompression limits, then
  converted by Sharp to metadata-free compressed WebP (maximum 5 MB). The output
  is shown as a temporary data URL in the browser, never persisted into a theme.
- Only **on confirmation** does the browser use the existing `/ops/themes/upload`
  API to persist the image in Saleor media. A failed generation/upload does not
  change the draft. Only saved draft/publish actions affect stored storefront
  page documents.
- Credentials are encrypted with AES-256-GCM in libSQL, never sent to the browser
  by the provider GET endpoint. Only deployment-admin-approved, exact HTTPS
  gateway URLs are accepted. The `/ops` authorization middleware applies to
  provider, generation and upload routes. CSRF checks reject foreign origins.
- Each instance enforces a brief model-request cooldown. **Production multi-replica
  deployments must also enforce a shared /ops/themes/ai/images/* rate/quota limit
  at the reverse proxy** because model calls are billable.
- API exceptions and unsupported models are reported without leaking API keys or
  provider response bodies. A broken model cannot break the storefront.
- AI-generated visuals must be reviewed for invented product details or claims;
  this flow intentionally does **not** overwrite Saleor product/SKU images.

## Deferred interfaces

`ai-core.ts`, `ai-assistant.client.tsx`, and
`/ops/themes/ai/generate` remain for future conversational page editing.
They are **not used by the active Puck UI**. Keep the default-off backend
guard in place until a separate reviewed release.
