# Saleor 分析后台 UI/UX 规范（V3.1）

## 设计基础
- 旧版 Commerce Analytics Preview 为视觉基准：深色左侧导航、浅灰页面、白色信息卡片、细边框、紧凑表格。不得以蓝紫色主题整体替换。
- 优先复用现有 Saleor/Paper 的 `bg-card`、`border-border`、`text-muted-foreground` 等设计令牌。
- 数据总览优先在卡片内部切换；确有必要时使用大型可关闭浮层，不默认导航离开页面。
- 卡片时间、渠道、地区选择局部生效；页面级筛选才影响全页。卡片标题栏操作位固定右上角。
- 趋势曲线逐时间桶展示。指针浮层必须展示对应时间真实数值；点击固定、再次点击释放；不使用假随机数据。

## 流量构成
- **环形图始终展示渠道流量分布，不允许切换指标。**
- 同一张卡片中同时可见：`渠道 | 流量 | 加购 | 订单 | 转化率 | 收入`。
- 表头不写“占比”；但流量、加购、订单、收入单元格展示份额百分比。
- 转化率为该渠道购买会话数 / 该渠道会话数，**不是**渠道订单份额。
- 流量、加购、订单的分母均为同一地区、时间范围内相应指标的总量。
- 收入占比每个币种单独计算，不把 USD/EUR/JPY 直接相加。没有可比收入或分母为零时显示“—”。
- 保留自然、付费、Direct、Referral、其他以及无法确定归因的分类；不能将 unknown 强制算作自然流量。
- Top 来源保留相同口径，可使用“查看全部”打开大浮层。

## 商品表现
- 卡片内切换“商品分类”和“具体商品”。
- 商品行展示缩略图、最多两行商品名、SKU、浏览、加购、订单、总转化率、付费转化率、自然转化率和已追踪商品金额。
- 具体商品图片优先使用真实 Saleor 商品图片。未连接图片数据时用中性缺省图；**禁止随机外部图片冒充商品图**。
- 分类及 SKU 归因仅在可靠关联事件与商品元数据后显示，不以假数据填充。
- 付费/自然商品转化率：对应来源购买会话数 / 对应来源商品浏览会话数。
- 商品成交金额不在缺少逐 SKU 退款分摊时冒称为商品净销售额。

## 经营趋势与货币口径
- 时间：今日、近 7 日、近 15 日、本月、自定义；该卡片的时间独立于全局筛选。
- 同时支持全站与地区趋势对比、单独图例、时间气泡。
- 下方固定显示总销售额、退款、运费、净销售额。没有独立可靠运费时明确显示“—”，不得将运费默认为 0。
- 未定义统一兑换汇率和财务时区前，币种分开展示；时间桶以 UTC 统计，之后可设置商店时区。
- 详情使用宽幅浮层，右上角有关闭键，支持 Esc；内容区滚动，不遮挡关闭操作。

## 运行与安全
- Analytics 数据库未配置、暂时不可用、没有数据，分别用明确的状态解释；不要展示演示值作为真实经营数据。
- 实时在线定义必须基于近期已追踪会话活动，不得宣称真实 WebSocket 在线连接。
- 不在 UI 展示原始用户敏感标识或广告点击 ID。
- 窄屏表格使用横向滚动，数据不发生重叠。
- 正式合并前应执行 TypeScript、Lint、相关单元测试以及浏览器 E2E。
